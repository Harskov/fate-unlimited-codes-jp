# Names and their evidence — Fate/Unlimited Codes

Every name in this repository that is not a placeholder, with the facts it stands on. A name is written only after a script has checked each cited fact against the code and every word of the name against those facts; this page lets anyone check them again. A placeholder (`func_00123456`, `unk_1C`, `D_00123456`) is a thing no checked fact names yet: it is better unnamed than named wrongly. Generated from the ledger at each publication; never edited by hand.

Classes of evidence:

- anchored — a fact in the artifact that carries the name (a string, an SDK prototype, a library symbol)
- propagated — a neighbour's checked name (a caller, a callee, a member assigned from another)
- behavioural — what the matched code demonstrably does (a mask test, a loop bound, a self-pointer); descriptive words only
- original — an identifier the artifact kept
